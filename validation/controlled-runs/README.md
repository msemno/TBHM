# Retained control-run exports

These folders retain selected reports, ledgers, timings and inventory documents
from owned temporary fixtures. They are metadata exports, not complete delivery
directories: the inventories also reference files that were cleaned up with the
temporary fixture. Do not claim a complete capture/delivery from these four files.

The tests verified strict proof and delivery integrity while the complete
temporary run existed. Recreate the full run using tests/test_incident_workflows_v426.py
and the supplied fixtures to inspect new captures. Final case counts and build
receipts are in validation/SUMMARY.json and the accepted test/integration folders.
