The phase contract also requests adding phases while requiring exact phase-list
equality. This release preserves the 145-phase list and adds guarded capability
hooks to existing phases. Only parser declarations/routing for new explicit input
flags are added; existing controller functions/classes other than `parse_args`
remain AST-equivalent.

No third-party target, paid service, external collaborator, live browser or model
training task was used to produce the validation evidence for this release.
