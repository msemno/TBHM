# Integrated roadmap after 4.2.5

The master development specification retains persistent learning, review, RAG, independent evaluation, mistake feedback, optional fine-tuning preparation and Kali resource constraints. Scanner milestones supplement it. No requirement is removed to make a milestone count look complete.

| Milestone | 4.2.5 state | Exact remaining prerequisite/work |
|---|---|---|

| M2 sensitive-writer closure | OPEN; new learning writers bounded and tested; full inventory supplied | Producer-lifecycle semantic review of every writer, all binary/archive formats, all-encoding canary and mutation coverage; unknown formats block universal claim |

All five broad finish-line flags remain false. `scripts/check_release_v425.py` accepts the measured incremental release; `scripts/check_done.py` rejects high-level scanner completion. Existing phases, CLI signatures, deterministic authority and safety gates remain compatibility constraints for future releases.
