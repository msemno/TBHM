# Remaining gates after 4.2.4

| Priority | Gate | Delivered | Missing acceptance |
|---|---|---|---|
| P0 | Global online traffic containment | Supported origin/IP-pinned native/fixed-pipe replay, shared requests/accepted decoded bytes/pacing/cooldown/serial lock | Migrate every urllib/native, scanner, browser, proxy and helper path; real headless and OS egress tests; define/measure all-wire units. Global flag stays false |
| P0 | Full sensitive-writer closure | Visible candidate/producer inventory; semantic review of changed paths; more encodings and bounded BZip2/XZ | Review every actual indirect/native writer and lifecycle; pixel/PDF/encrypted formats; unknown secret/PII detection. No full-closure claim |
| P0 | Additional strict classes | Two new narrow traversal/BFLA contracts; three old classes preserved by executable vectors | SQLi, XSS variants, SSRF/OAST attribution, SSTI, deserialization, auth/session and CSRF require independent safe oracles, controls, repeats, tamper and benign fixtures |
| P1 | Stateful API writes and tenants | Existing owned-object BOLA; owned-role protected reads | Owned multi-tenant fixtures, identity transitions, expiry/session controls, explicit reversible writes and verified rollback |
| P1 | Proven attack chains | Typed observation associations and capture traceability; no auto escalation | Authenticated per-edge preconditions/effects and scope-bound reviewed chain execution. Model proposals alone cannot confirm |
| P1 | Representative detector evaluation | Stage/class abstention-aware framework; paired four-case confirmation evaluation; 42 old behavioral vectors | Independently labeled project/time/class-disjoint real discovery corpus and reproducible held-out evaluation; no field accuracy inference |
| P1 | External runtime integrations | Existing optional interfaces and reviewed overlap retained | License/runtime/resource validation, adapter containment and actual vendor-specific local fixtures. No blank wrapper or catalog-only COMPLETE state |
| P1 | Full standards coverage | Existing execution-backed mappings retained | Requirement-level executed evidence and mobile/device/chain fixtures; CWE names and phase completion are not full coverage |
| P2 | Model quality / RAG comparison | Existing advisory context/evidence references/imports/corpus protection retained | Authorized model/runtime/dataset, deterministic/RAG baseline, injection/citation/evidence tests and actual RAM/VRAM/latency/quality measurements |
| P3 | Fine-tuning | No training or new weights | Documented permission/provenance, redaction/dedup/revocation, disjoint evaluation and demonstrated gain over simpler baselines |

These remain gates for broader automation, not hidden claims of the incremental
release. Critical tests for implemented paths must pass before packaging is
presented as validated. Unavailable models, external tools, headless runtime and
representative authorized corpora are recorded as unverified/deferred rather than
fabricated results. The revised contract now permits future additive proof
development and appended phases without changing old phase ordinals.
